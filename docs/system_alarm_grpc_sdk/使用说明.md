# 系统告警 gRPC 对接说明

外部系统向 **AlarmSys** 上报 / 取消 / 查询系统级事项告警。

## 1. 连接地址

| 项 | 值 |
|---|---|
| 主机 | `192.168.18.141` |
| 端口 | `25071` |
| 完整地址 | **`192.168.18.141:25071`** |
| 凭证 | 明文（Insecure，无 TLS） |
| package | `alarmsys.grpc.system_alarm` |
| service | `SystemAlarmService` |

Proto 文件见同目录 `system_alarm.proto`。

## 2. 接口一览

| RPC | 说明 |
|-----|------|
| `ReportAlarm` | 上报告警；同 `alarm_id` 重复上报视为更新 |
| `CancelAlarm` | 按 `alarm_id` 取消告警 |
| `GetActiveAlarms` | 查询当前未取消的告警（可按系统/类型/级别过滤） |

## 3. 系统 ID（`system_id`）

| system_id | 系统 |
|-----------|------|
| `sys-001` | 融控（NexusUI） |
| `sys-002` | 作战管理 |
| `sys-003` | 实体管理 |
| `sys-004` | 任务管理 |
| `sys-005` | 相机管理 |
| `sys-006` | 无人机管理 |
| `sys-007` | 告警管理 |
| `sys-008` | 数据管理 |
| `sys-009` | 雷达管理 |
| `sys-010` | 航迹管理 |
| `sys-011` | 数据转发 |

## 4. 告警类型 / 级别

**AlarmKind**：`EQUIPMENT=1` 装备状态 · `DATA_COMM=2` 数据通信 · `TASK=3` 任务 · `ENVIRONMENT=4` 环境 · `COMPREHENSIVE=5` 综合 · `SYSTEM_AUTH=6` 系统权鉴

**AlarmLevel**：`LOW=0`（默认）· `MEDIUM=1` · `HIGH=2`

## 5. 字段要求

### 上报 `ReportAlarm`

| 字段 | 必填 | 说明 |
|------|------|------|
| `alarm_id` | ✓ | 建议 `alarm_{短名}_{毫秒}`，如 `alarm_camera_1721020800123` |
| `system_id` | ✓ | 如 `sys-005` |
| `description` | ✓ | 告警描述 |
| `timestamp_ms` | ✓ | 本次消息时间戳（毫秒） |
| `raised_time_ms` | ✓ | 告警产生时间（毫秒） |
| `alarm_kind` | ✓ | 1~6 |
| `entity_id` | | 关联实体，可空 |
| `level` | | 默认 LOW |
| `canceled_time_ms` | | 上报时填 0 |
| `reserved1/2/3` | | 保留 |

### 取消 `CancelAlarm`

| 字段 | 必填 | 说明 |
|------|------|------|
| `alarm_id` | ✓ | 要取消的告警 |
| `system_id` | ✓ | 取消方系统 ID |
| `timestamp_ms` | ✓ | 取消请求消息时间戳（毫秒） |
| `canceled_time_ms` | ✓ | 告警取消时间（毫秒） |
| `reason` | | 取消原因，可空 |

不存在的 `alarm_id`：`ok=false`，`message=not_found`。

### 查询 `GetActiveAlarms`

| 字段 | 说明 |
|------|------|
| `system_id` | 空=不过滤 |
| `alarm_kind` | `UNSPECIFIED(0)`=不过滤 |
| `level_filter_set` | `false`=不过滤级别；`true` 时按 `level` 过滤 |

## 6. 调用示例（grpcurl）

需本机已安装 [grpcurl](https://github.com/fullstorydev/grpcurl)，且能访问 `192.168.18.141:25071`。

```bash
# 上报告警
grpcurl -plaintext -import-path . -proto system_alarm.proto \
  -d '{
    "alarm": {
      "alarm_id": "alarm_camera_1721020800123",
      "system_id": "sys-005",
      "description": "相机 camera_004 掉线",
      "timestamp_ms": 1721020800123,
      "raised_time_ms": 1721020799000,
      "alarm_kind": "EQUIPMENT",
      "entity_id": "camera_004",
      "level": "HIGH"
    }
  }' \
  192.168.18.141:25071 alarmsys.grpc.system_alarm.SystemAlarmService/ReportAlarm

# 查询当前告警
grpcurl -plaintext -import-path . -proto system_alarm.proto \
  -d '{"system_id":"sys-005","alarm_kind":"EQUIPMENT"}' \
  192.168.18.141:25071 alarmsys.grpc.system_alarm.SystemAlarmService/GetActiveAlarms

# 取消告警
grpcurl -plaintext -import-path . -proto system_alarm.proto \
  -d '{
    "alarm_id": "alarm_camera_1721020800123",
    "system_id": "sys-005",
    "timestamp_ms": 1721020900000,
    "canceled_time_ms": 1721020898000,
    "reason": "已恢复"
  }' \
  192.168.18.141:25071 alarmsys.grpc.system_alarm.SystemAlarmService/CancelAlarm
```

## 7. 接入步骤（各语言通用）

1. 用本目录 `system_alarm.proto` 生成客户端代码（`protoc` + 对应语言 gRPC 插件）
2. 创建到 `192.168.18.141:25071` 的 insecure channel
3. 调用 `SystemAlarmService` 三个 RPC

响应 `CommonAck`：`ok=true` 且 `message=ok` 表示成功；参数错误为 `invalid_param:...`。
